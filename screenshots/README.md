# Investigation Screenshots

This folder contains screenshots captured during the Windows Security Log Analysis project using Azure Data Explorer.

The screenshots provide visual evidence of the KQL queries executed and the results returned during the investigation.

## Investigations Captured

- Failed logon attempts (Event ID 4625)
- Successful logons (Event ID 4624)
- Account creation (Event ID 4720)
- Special privileges activity (Event ID 4672)

All screenshots relate to a synthetic training dataset and do not contain real security incidents.
